What it does

  • Go protocol foundation and node under cmd/syjd and internal
  • Python reference/oracle implementation for compatibility and regression work
  • Peer-to-peer networking and authenticated communication
  • Transaction, wallet and persistent storage components
  • Phase 10.1 400-block consensus-path validation report

Architecture

The Go node is the production-track implementation. The Python code is retained as a reference/oracle implementation. Cosmos SDK and CometBFT are proposed future architecture, not shipped components.

Engineering evidence

TESTING.md states 231 tests currently. The same document later records 244 passing tests; a blockchain site reports 250, and a Phase 10.1 report records 262 Python tests plus a 400-block Go consensus-path experiment. These figures describe different checkpoints and are not interchangeable.

Latest default-branch workflow (main): success on 12 November 2026 — Build 1 C-1 Verification.

Evidence snapshot: Verified 17 November 2026. Product test suites were not executed by this website build.

Limitations

The repository states NOT PRODUCTION-READY and NOT MAINNET-READY. Production-toolchain validation and security scanner execution remain outstanding in the current documentation.
